## 这是什么

一份**开箱即用的 Hermes 初始化方案**。它解决一个真实痛点：Hermes 装好后默认是个**能力很强但完全不认识你**的"陌生外包"——不知道你的生意、你的标准、你的雷区，会礼貌敷衍、编数据、等你指令。

这套方案让 Hermes 在**首次对话时**就完成对你的画像，把它从"陌生人"变成"懂你、替你扛活、敢反驳你"的 AI Agent 合伙人。

## 两个文件

| 文件 | 给谁 | 作用 |
|------|------|------|
| `hermes_onboarding_guide.md` | Hermes 执行 | 一键初始化的完整执行脚本（Q1~Q9 + 写入映射 + 规则） |
| `hermes_onboarding_methodology.md` | 给人看 | 方法论说明，讲清楚"为什么这么做" |

## 核心特性

- **新用户**：完整初始化，零配置零学习直接上手
- **老用户**：自动增量升级，只补缺的字段，**不重走、不动已有配置**（零副作用）
- **版本机制**：统一版本自适应，后续升级喂新版即增量
